COMMON RULES (wave 4, repo TFG — browser co-op horror/RPG extraction game, Vite + three.js + Rapier + Trystero P2P):
- First read CLAUDE.md, AGENTS.md §0 and §5.14 handoff, §7 Gotchas, and docs/MASTERPLAN.md sections relevant to you. Look at 2-3 existing wave-3 modules (e.g. src/game/cycle.js, src/game/worlds2.js, src/game/shipyard.js) and copy their idioms.
- Module pattern: create src/game/<name>.js exporting install<Name>(game) returning an API object with dispose(). In src/game/game.js replace ONLY your own placeholders `// [import:<name>]` with `import { install<Name> } from './<name>.js';` and `// [slot:<name>]` with `this.useModule('<name>', install<Name>);`. Do not touch other slots/lines of game.js unless strictly needed.
- Hook via game.mods.on(event, fn) (netReady, registerHandlers(H,g), phase, update, stats, interactables, useItem, objectives(add,g,phase), chat...). Networking is host-authoritative; game.net.on_(type, fn) keeps ONE handler per type → use unique message types prefixed with your module name. broadcast also delivers to sender. Deterministic RNG from src/core/rng.js for anything seeded; keep scene light count constant (use emissive materials / LightPool, never add THREE lights per object). Host timers via game.later.
- All player-facing strings via t()/tf() from src/core/i18n.js with EN + TR + RU entries (see docs/wave2/i18n.md; tools/i18n_audit.mjs).
- UI: avoid the generic "AI-looking" style — use the existing HUD/dock look (src/ui/dock.js hudDock, existing panel CSS), no emojis spam, no gradient-blob cards, no overlapping text; must work at 1280x720.
- Budget: you are on a tight API budget. NO browser playtests / headless harness runs unless absolutely needed (at most one short run). Verify with: node --check on changed files, small node unit tests under tools/sim or a test file next to your module (run with node), and `npm run build`. NEVER rm -rf node_modules (it is shared; a symlink).
- Keep scope tight, finish what you start; prefer fewer finished features over many half ones. Game goal: more fun, original (not a Lethal Company clone), fair early game.
