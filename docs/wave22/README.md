# Wave22 — Echo Runner follow-up

While Wave21's final gauntlet ran, the owner requested a purchasable ground bot that bounces off walls, draws creature attention and explodes. Echo Runner is an original neutral industrial PSX speaker cart, integrated into the existing consumable shop, grenade deployment, creature hearing and host damage systems.

Base price90credits buys one charge. Hold/release the normal primary-use button to deploy. The host drives the bot at2.8m/s, checks its full collision volume against walls/closed doors and emits hearing pulses every0.8s. Nearby hostile LOS or the9s lifetime starts a1.2s warning before a small blast. Distance/wall checks limit damage to75 for ordinary creatures,35 for bosses and18 for crew. Two bots per owner/six total keep the action bounded. See [runtime](boombot.md), [purchase](shop.md) and [art/audio](art.md).

The original model uses five batches/460triangles with no added lights. Private projectile resources dispose once; held materials follow the existing render-cache ownership. Native host snapshots replicate movement/warning and support active-bot reconstruction. Indoor bots become harmless duds when the facility streams; outdoor bots continue. No second inventory, wallet or projectile ledger is introduced.
