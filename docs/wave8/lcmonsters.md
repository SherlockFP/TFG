# Wave 8 - LCMONSTERS (module `lcmonsters`, src/game/lcmonsters*.js, src/models/lcmonsters_models.js)

Owner ask: creatures in the spirit of the Lethal Company mods Blood Witch, Lantern Keeper, Light Eater (NOT here: `crdirector`), Trick-or-Treat, Cursed Scraps, Stranger Things; "I never saw mimics"; outside as dangerous as inside, but not overdone. Concepts only (from the mod titles), everything is our own PSX design with the Algorithm / live-stream flavour. No THREE lights are ever added (glows are basic / additive materials; the flicker touches the `flicker` field of existing light-pool emitters).

Files: `lcmonsters.js` (installer, host director, requests, prompts), `lcmonsters_ai.js` (defs + host AI + registration), `lcmonsters_core.js` (pure rules, node-testable), `lcmonsters_fx.js` (client visuals, local curse effects, HUD chips, captions), `lcmonsters_text.js` (TR + RU), `lcmonsters_models.js`. Net prefix `lm`. Test: `node tools/harness/lcmonsters.test.mjs` (18 checks).

## Knobs (all in `lcmonsters_core.js` TUNE unless noted)
`budget` scheduled events per landing (2 for quota 0-2, 3 from quota 3), `earliest/latest` (45-330 s), `duskMin`; witch `circleR/circleLife/castS/curseExposure/bleedT/bleedDps/bleedFloor`; keeper `beamRange/beamHalf/markT/markPing/snatchReach/lanternValue`; `curseChance/curseCap/curseValueMul/cleanseBonusKeep`, `heavyMul`, invert / whisper / lure timings; `osWarnS/osRiftS/osHunter`; `maskLatchS/maskWarnS/maskedMax`; creature HP / dmg / speed in `lcmonsters_ai.js` DEFS. `kindWeights` sets which kinds exist at which quota (no Rift Stalker / Masked at quota 0).

## How it fits the rest
- Spawns are gated by `game.crdirector?.canSpawn?.(type, pos) === false` (missing = allowed) plus own caps: max 1 alive of each kind (Masked 2), `noSpawn` in every def so the generic spawner never rolls them, `affix: null`.
- balance_rules: no dmg > 90, no instakill, all hits go through `CreatureManager.attack` (0.4 s wind-up + hit cap + sector scale); Masked uses `hostHoldPlayer` (escapable). Bleed is client-side and floors at 12 HP.
- Shared edits (each 1-2 lines): `game.js` slot/import, `actions.js` (scan skips `def.noScan`, emits `scanLabels`), `identify.js` `gated()` (noScan), `screens.js` (radar skips noScan), `localplayer.js` (`game.lmMove.invert` / `speedMul`).
- Net: `lm` host -> all (HOST_ONLY): `ci cx bl mk os tt sn mw ml cu cc cm drop cl`; `lmq` client -> host: `mg` (grab mimic) `sn` (snatch lantern) `tt` (treat) `cl` (purge curse). Late joiners get the curse map (`cm`).
- Debug: `kefal.game.lcm.debugSpawn('keeper'|'treat'|'witch'|'otherside'|'lootmimic'|'masked')`, `lcm.state()`, `lcm.debugCurse(itemId, 'heavy'|'whisper'|'lure'|'invert')` (host).

## Unverified (no browser run: the shared browser lock was jammed)
- Nothing here has been seen in the game. Node tests use fake managers / a fake game; the client fx (circles, rift, sign, flicker, chips, name tag), the models (proportions, mask position on the avatar head, beam cone orientation, item look-alike scale of the Loot Mimic) and audio picks are guesses to eyeball first.
- Blood circles are flat discs at the witch's foot height: on steep terrain they clip. LOS uses `physics.lineOfSight(STATIC|DOOR)`: check terrain is a STATIC collider outdoors.
- Cursed-scrap markers are not saved: after a reload the item keeps its x1.6 value but loses the curse. The 'val' broadcast for a raised value assumes items exist on peers ~120 ms after spawn.
- The Masked wanders via `M.wander/follow` (nav grid) but chases with `moveToward` (straight line): may hug walls.
- Trick teleport picks a random facility scrap spot >= 25 m away; no check that it is safe / connected.
- The Blood Witch only spawns on moons with a terrain (outdoor) at dusk; check her against the day clock on a real landing (17:20 = ~420 s at the default day length).
