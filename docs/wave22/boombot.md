# Wave22 — Echo Runner

The native consumable catalogue now sells Echo Runner (`bouncebot`, base price 90, one charge). Hold the existing primary-use button and release to deploy; cooking cannot shorten its nine-second lifetime. It is an original ground speaker robot, not a copied asset.

The existing grenade `balls` ledger owns deployment, host damage, replicated effects and disposal. The host derives travel from the owner's actual horizontal look and validates held ownership, positive charge, known living/non-downed actor, origin distance/LOS and volume clearance before consuming anything. Accepted requests share the existing 0.3-second cooldown. Limits are two active runners per owner and six total. Replay, invalid ownership or cap rejection leaves the item intact.

Movement uses native Rapier cuboid sweeps (0.22m half-extents), bounded 1/60s substeps, wall reflection, gravity and ground contact. It travels at 2.8m/s, emits native creature-hearing noise 2.6 every 0.8 seconds, and stops horizontally for a 1.2-second visible/audible warning. A nearby eligible hostile must have wall/door LOS to trigger early; otherwise the warning begins before lifetime expiry. The native blast applies distance falloff and wall LOS: up to 75 creature damage, 35 to bosses and 18 to crew. Falling far below the launch floor produces a harmless dud.

Host position/velocity/warning snapshots use the existing host-only `grfx` channel at 10Hz; peers interpolate visuals. `grrs` reconstructs active runners for a known joining actor using the same ledger. A promoted peer retains the most recent native snapshot and resumes simulation; no persistent projectile save or second economy ledger is introduced. Network loss can extend a warning slightly on migration; it does not intentionally shorten it. Phase/unload cleanup remains native. `facilityWillChange` cancels indoor runners without damage while leaving surface runners alive during floor replacement.

Validation: installed native grenade harness with real Rapier floor/closed-door sweeps, actual registered requests and host/peer messages covers consume-once, host-derived direction, reflection/grounding, native noise API pulses (not a forced-aggro assertion), peer interpolation, invalid requests/owner cap, warning duration, native boss/crew damage limits, single detonation, blocked proximity LOS, floor cancellation and snapshot recovery. Existing grenade-core radius/cooking coverage passes (137 assertions). Separate actual shop and model/audio fixtures cover catalogue quote/delivery/custody and owned-art disposal. Browser validation is owned by the shared QA agent; these harness results do not claim browser performance or human playtest completion.
