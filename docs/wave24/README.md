# Wave24 — Card Archive and Dead Letter Run

The owner requested implementation of the separate survivors-style mode, personal three-card choices at every earned level, rarity tiers and repeat ranks, additional labyrinths and NPC blackjack/poker. Starting published baseline: `a4ad817`. Root owns the authorized combined main commit and push after verification.

Dead Letter Run is an optional co-op expedition entered beside the ship terminal in a safe orbit/Company state. LMB throws physical archive slips; R selects a returning, bouncing or slowing special for the next throw. Three authored sorting-floor themes support short exposed and longer covered approaches. Three waves precede a Return Warden boss on every floor; living crew regroup at the descent cabinet before going deeper. Theme families repeat with bounded enemies and difficulty. This is a playable first release, not an unlimited unique boss/content catalogue.

Every earned level queues a personal choice of three usable cards. Ten mechanics use Common/Rare/Epic/Legendary tiers and repeat rank1–5, capped at level41. Temporary XP/builds do not award campaign money, quota, profile kills or permanent upgrades. Safe bounded upgrade breaks pause enemy attacks; downed rescue remains live. Host validates tokens, floor revisions, peer identity, replay, direction, physical trajectories and draft choices. Actual campaign checkpoint items retain their original IDs and custody on return; host migration ends the temporary expedition safely rather than pretending to continue an unverified boss.

Normal exploration also gains three routable destinations using those authored interiors with conventional finite salvage/creature budgets. Hidden zero-loot trials are excluded from normal charts and denied by the actual terminal host routing path.

Card Archive has six physical stations: cashier, reels, wheel, Packet, blackjack and five-card draw poker. Blackjack supports hit/stand against the NPC dealer; poker supports one0–3-card exchange followed by full hand comparison. Closing a panel retains the same hand. Native personal chips, shared Credits and host station/sequence validation remain the only casino ledger. Slot return is201/216; new Packet stopping strategies no longer produce expected redeemable profit. Accepted stakes/maximum payouts reserve liability; visits and loading cannot refill it. Secret dealer hands/decks remain private across all remote snapshots, nested checkpoints and migration.

The casino uses eight merged batches,2162 triangles, one low-resolution atlas,15 owned static colliders and no extra lights. Actual native standing controllers verify all six table approaches and the sale route. Projectiles, actor counts and map/resource ownership are bounded; these engineering limits do not establish hardware FPS.
