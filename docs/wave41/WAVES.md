# Native exterior waves

`installEndless41Waves(game)` supplies `tick(dt)`, `owns(c)`, `spawnOptions(type,pos,opts)`, `afterSpawn(c,opts)`, `onKill(c,by)`, `creatureTick(c,dt,manager)`, `canMove(c,x,z)` and idempotent `dispose()`. Root exposes `ownsCreature` as an alias. The root Endless host update calls director and native CreatureManager once, then publishes the run keyframe every half second. The director advances only `run.endless41.elapsed`; native moon time, creature age, stun, attack cooldown, snapshots, deaths and phase transitions retain their owners. Invalid/nonpositive time steps are ignored; an accepted director step is capped at0.25s. No additional timer, physics actor pool, wallet or permanent progression is introduced.

Every landing starts with90s quiet time and a6s host-broadcast region warning. A batch begins every75s after the first warning, provided a physical region is available. Early batches contain2,4,6 and8 actors. Simultaneous living capacity starts at12, increases by4 every four waves and stops at32; a full pool holds the pending batch until capacity returns. Each batch spawns at most one actor per1.2s. Failed region search retries every2s, with at most four regions and24 seeded candidates per region. Killing the living batch creates a break until the next scheduled warning. Root starts each trip at wave0; persistent `totalWaves` contributes at most12 extra base health, so an extraction preserves slight difficulty growth without skipping small opening batches.

The director reuses PSX zombie accounts and hunter spiders. Walk/run speed is1.1→2.3m/s, base health28→100, and base hit damage6→18. Every fourth wave has one elite with1.7× health and1.3× damage. Ordinary forge, descent and chase/balance speed tuning do not alter owned actors. No optional random ammunition/cell drop was added.

Spawns require at least18m from the ship and20m from every nondead native player body, including a revivable crew member. The anchor is the first connected standing exterior crewmate, or a point beyond the native boarding steps. Seeded candidates remain inside the terrain boundary with a3m margin; blocked terrain, lava and flooded acid are refused. Native Rapier floor rays require a walkable normal; actual capsules reject static geometry, doors and large colliders. A sampled exterior corridor checks floor height changes and solid LOS before admission. Owned movement repeats those floor/capsule/step/LOS checks. Its narrow approach exemption permits travel inside the ordinary9m ship exclusion only with physical proof; actors still cannot enter the ship. Unavailable routes yield safely and are never repaired by teleport or a LOS bypass.

Native connected, nondead, standing exterior players can be hunted within65m. Rescue-ledger downed state is authoritative even if `aiPlayers()` omits a downed flag. Player strikes require1.5m range, compatible height, solid LOS,0.45s windup and native1s spawn age, with a1.5s cooldown. Without an eligible exterior target, actors approach the exterior door point. Ship strikes require3.5m actual distance and solid LOS to that point, with the same windup; damage is capped at12, one accepted hull strike per second globally and a3s cooldown per actor. Root owns ending the run when hull health reaches zero. Preparation, a mismatched/unloaded map, demotion and the over stage stop the director; over stage owned actors stop movement and damage.

Ownership is the bounded `{token,map,wave,index,elite}` receipt. `map` is native `moon:seed:day`; spending/offer revision does not orphan an actor. A fresh actor needs a private, once-consumed director ticket. Normal directors, forged tickets, unknown restoration IDs, stale receipts and a restored position different from its retained native view are refused. Native spawn/late-join packets carry only the accepted receipt, while HostMig restores it from the actual native view and rechecks physical floor/capsule placement. A promoted host reconciles a partially spawned batch from accepted actor indices, covering a newer spawn view arriving before the next ledger keyframe. Native map-loaded cleanup removes stale mode actors; disposal removes only director subscriptions and tickets, while native map lifecycle owns actor teardown.

An actual native death awards run XP once:18 to its known connected killer,9 to each actual connected assistant; elite values are30/15. Normal coins, XP, drops and normal kill reward hooks are bypassed for owned actors. Unknown pseudo killers earn no XP. The actual shipyard turret source, `sytur`, can credit the connected living `turretOwner` recorded by root purchase admission. The director does not attribute arbitrary pseudo sources. Root owns the temporary offer ledger and profile isolation.
