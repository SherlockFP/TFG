# Wave21 — The Algorithm's depth archive

The owner requested a quieter first landing, exploration tiers and a crew lift into progressively deeper procedural facilities. The later Tower of God suggestion informs the structure: each level has a different atmosphere and one readable rule. These are original abandoned-network/archive spaces using TFG's existing industrial PSX art; no commercial characters, locations or models are copied.

The first quota-zero surface has a45-second roaming-threat grace period, then one roaming encounter until120 active moon seconds and two thereafter. Arrival pockets stay protected during that settling period. Features remain immediately accessible; campaign experience and optional encounter contracts still govern threats. See [pacing](pacing.md).

An actual physical lift unlocks after the crew discovers up to15 ordinary rooms in that floor. Call and transit take3 active seconds each. All living crew must board, downed crew must be recovered, and active pursuits/jobs must finish first. A direct return is available from depth without repeating the discovery requirement. Subsequent descent continues beyond the deepest floor reached; abandoned deep floors seal instead of rerolling their salvage. Native held items, bag custody and cabin cargo travel with the crew, preserving IDs and extraction-credit flags.

Each depth uses a deterministic seed, an existing interior theme and a short rule: archive retrieval, acoustic attention, inspection or heavy processing. Layout size, loot and ordinary threat pressure rise smoothly with fixed combat/population limits. The content combines a finite set of authored themes and creatures over generated floors; it does not create infinitely many bespoke assets. Native quota/species restrictions remain in force. See [floor rules](floor_rules.md) and [threats](threats.md).

Streaming replaces only the active interior. Outdoor terrain, ship, native economy and the single quota/day ledger remain. Deep transit holds the native extraction clock; surface return resumes it. The exact original surface generation, door states, remaining loose loot, spent indoor budget and darkness-collapse ledger are restored. A bounded isolated preflight certifies physical lift placement before committing the transition, with persisted alternatives for unsuitable generated layouts. No live physics simulation is advanced out of order.

The lift uses neutral steel, ivory and ochre with no new dynamic lights. Identical state updates do not redraw its canvas textures. Placement checks native furniture, doorway clearance and locked routes rather than assuming a grid cell is accessible. Unsuitable original floors stop placement retries after four attempts; they cannot continually repeat a costly physical search. A temporary jam is cleared from the surface checkpoint rather than becoming a permanent saved door lock. See [maps](maps.md) and [lifecycle](lifecycle.md).

Legacy surface activities are conservatively detached/suppressed while deep, retaining existing finite earned ledgers. Facility chests deliberately stay unavailable for the rest of that landing after a floor transition; outdoor chests retain their native identities. See [boundaries](boundaries.md).
