# Archive recovery — wave 14

One opt-in mission, available after quota two on ordinary facility landings with seed divisible by four and an actually reachable existing bonus vault. The generated vault and separate cargo source must pass nav checks. Other quota-two landings retain Expedition13; on a reserved archive landing Expedition13 returns early, so there is only one optional field job. If no safe plan exists the old expedition remains available.

The recruitment console sits at the bonus vault approach. Accepting creates exactly one Sealed Archive Cell (two hands, 6 kg, zero sale value) in a separate reachable room with a physical relay marker. Carrying that exact item back and installing it opens only the bonus-vault door, consumes the item and spawns one existing Access Card Holder boss as the archive guardian. The mission text calls it the Archive Custodian; its existing boss name/model/combat remain Access Card Holder. The shared cycle boss engine handles actual telegraphs, charge, stun guard, summons, chase and disengage. Solo HP is 315, damage 18, normal existing crew HP scaling; no phase two. The door stays open and the original path back to the entrance is tested. There is no timed trap or forced fight.

Acceptance and installation refuse while another live boss exists or Escape14 is active. Escape14 also refuses while this mission is active. The exact guardian's real host kill callback enables a finite cache claim: one physical Recovered Archive Cache worth 180 base credits, two hands, 8 kg, which must be carried home and sold. No direct credits, quota increment, repeated cell spawn, repeated guardian or repeated reward request. Existing boss XP/Clout and minion combat rewards still apply through the shared boss system. Existing generated vault salvage is unchanged and remains finite. Selling/losing the cell can abandon the optional mission until the next landing; it never respawns for farming.

Integration: root imports `installMissions14` and installs after `escape14`. Expedition13 contains the authorized one-line `game.missions14?.reserved(world)` map-load guard. APIs: `game.missions14.plan()` exposes `anchor`, `cellPos`, `bossPos`, `door`, `room`; `.state()` exposes token, stage, cellId, bossId, rewardId; `.active()` supports escape mutual exclusion; `.request(op)` emits `m14req` for accept/install/cache. Requests validate map token, active moon phase, alive/non-downed indoor player, proximity, actual carried item holder/type and stage. Host-authoritative state travels in run.mission14; welcome snapshots already include it. Same-map rebuild preserves stages and reapplies unlocked gate. Orbit clears state and module geometry; dispose restores keypad and doorInteraction/kill wrappers and removes owned item models.

The mission reuses existing floor, door animation/collider/nav release and merged console geometry. It adds no walls, locked main corridors, lights, map topology or separate boss AI. Cell/cache use existing procedural models under distinct inventory IDs and EN/TR/RU names/text.

Verification: `node tools/harness/missions14.test.mjs` builds eight real generated facilities and tests a valid vault: quota eligibility, stale rejection, single finite cell, uncarried rejection, Escape14 collision rejection, one real shared spawn API call, genuine Game.onDoor nav release, bidirectional entrance-to-boss retreat path, unchanged unrelated doors, exact killed-boss identity, finite physical cache and orbit cleanup. Existing expedition13 harness still passes. Browser experience, real Internet co-op and encounter difficulty require human playtesting; passing a mock spawnBoss API test does not prove the shared boss combat is fun. The vault is existing generated geometry, not a new authored arena.

Warm-set integration: eligible landings precompile the two artifact models and actual registered keyholder model through the existing `warm` event. Uses the already selected plan after mapLoaded replaces the keypad, so real landing queue ordering does not silently skip prewarm. Harness verifies three models both before and after mapLoaded. Confirmed QA fixture: seed 4, factory, size 0.8, quotaIndex 2.
