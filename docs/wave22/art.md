# Echo Runner22 original art and sound

createBoomBot22 from src/models/boombot22.js builds an original faceted industrial speaker cart: two rubber roller wheels, steel hubs/chassis, dirty ivory case, grille, carrying handle, rear battery and worn ochre trim. A separate small amber lamp supplies the native warning visibility hook; there are no scene lights, downloaded assets or broad green/neon surfaces. +Y is up and +Z faces the grille. The origin is the native collision center; rollers end at Y=-0.22, matching the deployed cuboid center resting at floor+0.22.

The same silhouette serves native held/world items and deployed projectiles. It uses five merged mesh batches and460 triangles, with bounds0.406×0.345×0.380m. Every XZ vertex fits radius0.22, so visible parts do not protrude outside the collision footprint. Existing native viewmodel handling owns carried positioning and the runtime owns deployed yaw, motion and lamp blinking.

GRENADE_MODELS.bouncebot uses the held factory with cached native render materials; this matches ItemManager's geometry-only item teardown and avoids allocating orphaned private materials per held item. createBallMesh('bouncer') uses private projectile materials. Both expose userData.led and idempotent userData.dispose. Projectile disposal frees private geometry/materials once; held disposal frees geometry without destroying the render cache.

BOOMBOT22_SOUNDS exports native (sampleRate)=>Float32Array generators: bb22_drive (0.32s mechanical motor), bb22_ping (0.42s two-tone packet chirp) and bb22_warn (0.16s ratchet beep). The warning stays shorter than the runtime's0.2s cadence to avoid overlapping beep layers. Controls registers the generators through native soundGens; no separate audio context or persistent loop is created here.

Validation: the model harness verifies actual geometry dimensions/round footprint/floor contact, five-batch complexity, finite transforms, lamp hook, no lights, once-only private disposal, shared held-material ownership, finite bounded deterministic audio at16/48kHz, fade boundaries and warning cadence. This is a source/model/audio-sample check; ordinary-eye-height browser readability and human headphone quality remain unverified. Existing grenade core coverage initially reported the new kind's undocumented-radius assertion to its owning runtime agent for correction; this art lane did not weaken that test.
