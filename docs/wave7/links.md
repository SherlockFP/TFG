# Wave 7 - LINKS: connecting loose ends (no new module; small diffs in story / voyage / social / zones2 / algo2 / roledays)

Test: `node tools/harness/links.test.mjs` (50 checks) plus the existing story / story_host (91) / zones / zones2 / zones_host / zones2_host / algo2 / roledays / social / voyage tests.

1. **Voyage missions have patrons.** `voyage_core.MISSION_PATRON`: Company = blackbox, relay, drone, defend, hunt; Algorithm = rescue, survey, heist, photo. Offers + accepted missions carry `patron`; the `MISSIONS` terminal board shows `<COMPANY>` / `<ALGORITHM>`. `finishMission` emits `tfg:voyage {k:'done', patron}` on the mod bus; `story.js` handles it (host) with `story_core.applyMission`: `done[patron]++`, meter shift `AL.missionShift` (Company 4, Algorithm 5; contracts are 6 / 8), profile job count, unlock / tone announcements like a contract. Failed / dropped missions do not move the meter.
2. **Ship contract board shows patron jobs.** `contracts.js` panel: a PATRON JOBS section under the offers (title, brief, pay, loyalty shift, TAKE JOB button; disabled when taken, when a job is active or outside orbit). Data: `game.story.jobRows()`; the button calls `game.story.takeJob(i)` = the same `streq {op:'job'}` request as the terminal `JOB <n>` (host validates).
3. **Hub: trend + zone leaderboard.** Beacon `sop` gains an optional `zs: [zones owned, income/day, defences held]` (three ints <= 99999, only a lobby HOST sends it, only when it owns a zone or has held one; ~20 bytes). `hub_core.validateBeacon` validates it, `zoneRank` sorts. New hub tab **HUB**: this week's trending creature (computed locally with `story_core.trendFor(isoWeekKey())`, same result as the host's, works in the menu) and the CREW ZONE LEADERBOARD (online hosts + this crew). Not sent when the hub is off.
4. **Zones wall ghost mode.** Panel WALLS: GHOST WALL / GHOST GATE buttons close the panel and start a client-only ghost (`zones2.js`, translucent green / red boxes with the homeworld2 `GH` materials, hint line like homeworld2). Aim ray marches the terrain (`Q.aimGround`, reach `WALL.maxReach`), snaps to the wall grid (`Q.ghostPiece`), R rotates (default: across where you look), LMB places one piece (`znreq wall` with the snapped centre, `n:1`; the host validates exactly as before), RMB / panel / death / leaving the moon ends it. Colour = the same `validateWall` + credits + zone-owned + inside-zone checks run on the client. Panel buttons PLACE / x4 / LINE remain.
5. **algo2 ghost path clamp.** `algo2_core.clampTrack(track, anchor, nav)`: walking back from the anchor, every sample off the facility nav grid is snapped to the nearest walkable cell (radius 3) or holds the previous position; a step whose segment crosses a wall also holds. Applied once when the `gh` message arrives (client, `game.world.facility.nav`), so replays stay in corridors.
6. **Navigator minimap.** `roledays_core.showMinimap` (navigator holder flag `minimap`), `bakeGrid` (nav grid -> <= 128 px bitmap), `mapPoint`. `roledays.js`: a 10 Hz canvas in the right dock (`hudDock('right','rdmap')`), walkable cells, green EXIT (facility main door), blue SHIP (world origin, sticks to the border when off the map), yellow crew dots, white self + heading. Only while in a moon with a facility nav and only for the navigator. **Hook for the upgrade shop:** `game.roledays.addMinimapGrant(() => bool)` returns an unregister fn; any grant returning true shows the map to that peer (no upgrade item was added).

## Net
No new message types. `sop` beacon gets the optional `zs` field. Mod bus event `tfg:voyage`.

## Known gaps
Nothing here was run in a browser: the ghost look / hint position, the HUB tab layout, the PATRON JOBS cards at 1280x720, and the minimap size / position next to the role card are unverified. The ghost's LMB also reaches whatever the player holds (no input capture). Trend is not in the beacon (derived from the calendar, so peers agree anyway; a peer with a badly set clock sees another week). The leaderboard is only as honest as the beacons (no signatures). Navigator card text still says "only one with the compass" (key kept for translations).
