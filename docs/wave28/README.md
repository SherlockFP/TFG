## Player-facing rubric

The [independent review](REVIEW.md) defines observable usability, visual coherence,
readability, pacing, stability and cooperation criteria. Record confusion and
failed actions as carefully as successful ones. A naturally played solo route can
identify onboarding problems; it cannot establish cooperative fun or Internet
reliability. A source audit or regression pass cannot establish replay desire.
