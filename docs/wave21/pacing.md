# Calmer first surface encounters

Immediate feature access remains `all`; creature admission uses campaign position, not the skill/shop unlock mode. `firstdepth21` applies only to day-zero/one, quota-zero, depth-zero landing/moon phases with a real field facility, outside Quick Shift/company/home/ghost destinations. It reads native `hostData.moonT`; there is no parallel encounter clock, queue, saved flag or new HUD.

The first 45 active moon seconds admit no roaming threats. Until120s, the first surface allows one live roaming encounter, excluding very fast/high-hit types. The ship landing pocket, native outdoor entrance, main facility door and fire exits have a16m arrival buffer at the same vertical level. This covers scripted/direct spawns as well as normal waves. Up to two distant damaging static hazards remain discoverable; instant-kill fake exits wait through the settling interval. After120s, the first surface allows two live roaming creatures. Deeper floors, later days and later quotas retain native pressure unchanged.

Audit: native initial population creates turret/mine/fake exits then calls an indoor wave; later indoor/outdoor timers use host helpers. The director queues releases and can call the manager directly; scripted modules such as anomalies, optional encounters, expeditions and built-in creature mods also use manager.hostSpawn. Existing native early-safe filtering alone protects only selected host/director spot selection. The installed manager wrapper is the common admission boundary. Explicit ID restoration bypasses admission so host migration keeps prior identities/stats. Boss/cycle auxiliary spawn contracts, neutral authored patrons and harmless native/owned child actors remain intact. Authored neutrality uses native noSpawn/noHunt with zero power/rewards, rather than treating all noHunt scripted hostiles as safe. This is ambient pressure pacing, not blanket removal of optional systems.

Native indoor helpers can return true even when their manager spawn is rejected; the wrapper returns false in that case so native indoor power is not spent. Native outdoor helpers charge before attempting the spawn; rejected attempts refund only their own charge. No budget is refunded for an accepted spawn, no creature is silently removed, and no spawn/drop/reward ledger is duplicated. Normal native timers/director retries remain responsible for future population; no deferred spawn queue grows behind the scene.

`firstdepth21.test.mjs` constructs the real CreatureManager and invokes actual native indoor clustering/outdoor host methods. It verifies no fake spawn broadcasts during grace, one/two shared roaming caps, damaging hazard caps, ship/main/fire-exit protection, native budget refunds, direct scripted admission, death freeing a slot, restored identity/stat preservation, boss contract, and unrestricted deeper/later/quick behavior. Disposing restores all original methods. Existing first-run rules and creatures20 regressions pass. Game installer integration belongs to root; this lane changes no Game/host/creature AI source.

This fixture proves native spawn admission and pressure-accounting contracts. Browser field encounter pacing and human first-session feel still require the shared QA/owner playthrough; regression counts do not establish enjoyment.
