# Immediate system access

The owner requested that new games start with the available side systems open, specifically FLAPPY
PHISH, the incubator, skill tree and dining table. Runtime onboarding now chooses `mode: 'all'`
for both fresh profiles and previously staged saves. Existing quota, sale, boss and gift records remain
intact. Host hub publication carries that mode to joining players; native interaction safety guards
remain installed. Historical staged rule helpers remain compatible with old fixtures.

This opens system access rather than granting items or completed progression. Skill points and node
connections, food/egg ingredients, ship purchases and room upgrades, mission prerequisites and item
progression retain their native rules. No startup cosmetic gift cascade or extra wallet is introduced.
The obsolete settings switch for skipping system locks was removed.

The ship arcade now exposes original FLAPPY PHISH as the fifth menu choice, using its original game
and reward path. Dining installation requires the actual ship group and retries on native map/run
lifecycle events after temporary placement conflicts, cleaning up stations on ship replacement.
The courier service also accepts the shared all-access policy while preserving its native parcel
custody and finite reward.

See [stations.md](stations.md) for all four hulls and host/peer physical fixtures, and
[food_access.md](food_access.md) for native dining initialization and consumption checks.
Final regression and browser evidence are recorded in README and PLAYTEST after completion.

Beginner message and hazard pacing remains separate from feature access. Both native consumers use the same earned-experience context: first-shift pickups/sales do not release the calm budget, while established played days/quotas or level-four veterans retain normal pacing. Native flow, quota, quick-shift and explicit debug overrides remain intact. No new persisted flag is added. Updated installed checks: onboarding 642, mapmods 54; first-run pure rules and tree access pass.

The first broad access run passed 214/216 groups. Joinplay still expected the old locked fresh menu;
its assertion now checks immediate access. The homeworld integration fixture chose a random native
seed while authoring a heuristic factory route. A temporary seed-33 reproduction produced route
lengths 52/0 and the same dependent store/offline failures; the original random seed was not logged.
That integration fixture now uses native `X.blank(1)` and retains factory, power, store, offline and
peer assertions. Product seed generation is unchanged. The final broad rerun is recorded separately.

Final broad rerun: **216/216 passed in 273 seconds** (`-j 2`). The final focused access/pacing
run passed **11/11** groups; production build passed in **2.91 seconds**.
