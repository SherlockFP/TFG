# Wave24 — personal expedition drafts

Temporary mode XP uses `newProgress`, `gainXp`, `nextOffer`, `chooseCard` and `effects` from `deadletter24_core.js`. It never modifies profile XP, credits or skill points. XP thresholds are 24 + 12 × current level. Large gains retain pending levels and offer one choice for every earned level, in order. The bounded expedition maximum is level41: forty upgrades across ten rank-five cards guarantees three distinct usable choices at every legitimate draft, even with concentrated repeated selections. Extra XP at the cap is discarded; pending earned choices remain.

Catalogue rarity identifies mechanics and is separate from repeat rank. Common: damage, movement, attack interval, health. Rare (level4): critical chance, mitigation, range. Epic (level9): piercing and critical multiplier. Legendary (level16): returning passes. Seed/earned level/nonce/floor determine weighted draws without replacement (45/33/17/5 per eligible card). Rank-five cards are excluded. A rank increases by exactly one. Effects cap at damage1.6×, movement1.2×, crit17.5%, five pierce/return passes, interval0.775×, range1.4×, reduction20%, extrahealth40 and critical multiplier2×. The runtime must cap each physical attack's hit chain; this core does not schedule recursive procs.

State shape: `{seed,floor,level,xp,pending,build,offer,nonce}`. Choices contain `{id,nonce,level,floor}`. Exact authoritative offer/nonce, earned level, floor and current rank are checked before spending. The runtime authenticates the requesting peer against their personal state and active expedition. On a floor change, update `floor` and clear `offer`; `nextOffer` regenerates a fresh nonce without losing pending levels. This is intentionally not a saved permanent upgrade system.

`installDeadletter24Draft(game)` exposes `openDraft({offer,build,onChoose})`, `close`, `isOpen`, `dispose`. It uses actual native panel ownership and focus, without keyboard listeners or changing crouch/Escape bindings. A failed callback (`false`) leaves choices enabled; dispatch closes the draft once, and authoritative subsequent state can open the next pending offer. Opening refuses another panel, fullscreen/minigame, death or genuine danger; newly arriving real danger closes it while the server offer remains pending. The native mode’s bounded `combatPaused()` may permit drafting with living but paused enemies; an unpaused rescue/threat retains the blocker. Native Escape dismissal also releases input. The runtime decides when to reopen or expose the existing pending draft action, rather than reopening a dismissed modal every frame.

Three understated paper cards show rarity, current→next rank and actual effect values in EN/TR/RU. All CSS is owned by the module and reference-counted/disposed. Tests cover100 complete seeded forty-draft campaigns, XP boundaries/overflow, rarity gates, capped duplicate exclusion, replay/floor/invalid-card rejection and effect limits. The UI fixture calls actual `UI.openPanel`/`closePanel`: localized choices/focus, movement capture release, exactly one dispatch, native close, foreign-panel/danger refusal and style disposal. Browser/runtime gameplay validation belongs to shared QA.
