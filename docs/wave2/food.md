# Wave 2 - FOOD & DRINKS (module `food`; node-tested only, NOT hand-played, no browser run yet)

Files: `src/game/food_data.js` (pure: items, buffs, drunk maths, slur, cheers, table, placement, TR/RU), `src/game/food.js` (install), `src/models/food.js` (models, ship table, vending machine / fridge).
Tests: `node tools/harness/food.test.mjs` (877 checks), `node tools/harness/food_install.test.mjs` (stub game: eat, drink x3, cheers with a fake 2nd player, cake, offer/take, dispose).
Shared-file edits: `game.js` (import + `useModule('food', installFood)`), `anomaly.js` (1 line: food buffs get their own cap of 6 so they do not evict mutations / power-ups).

* **No hunger meter.** 14 consumables (`fd_*`, kind `consumable`, store tab **Food**, sold or found): Instant Noodles (regen), Deluxe Ramen, Pizza Slice (+30 HP), Pizza Box (+60), Energy Bar (+45 stamina), Party Cake (found; shared), Mystery Meat (creature drop; random good / bad), Mega Engagement (+30% speed 60 s, then The Crash), Doomscroll Coffee (quiet creature ping 32 m, scan +40%), Glitch Cola (random 25 s mutation), Cringe Juice (squeaky steps, -6% damage), Server Rack Lager / 404 Raki / Firewall Vodka. Almond Water is unchanged (static.js).
* **Buffs use the anomaly buff registry** (`game.anomaly.DEFS` gets `f_*` defs; left buff bar, expiry and `anst` sync are reused). One drunk band buff at a time (Tipsy / Drunk / Hammered / Legless) from the live drink stacks (each drink lasts 2-3 min).
* **Drunk** (stacks per drink): camera sway + blur, aim drift, delayed turning (look input low-pass), slurred outgoing chat (`sendChat` wrap), the crew sees sway / hiccup hops via `fds` state + the `remoteAvatar` hook. 3+ drinks = hiccups + blackout risk (fall, drop held item, 2.6 s, not lethal, 45 s cooldown). Courage refunds part of STATIC gain, +3% armor per drink.
* **Animations**: first person = `WEAPON_ARCS[itemId]` played on the viewmodel swing timeline (no avatar edits); third person = emotes `x:fd_eat / fd_drink / fd_burp / fd_cheers / fd_pass` (registered in `EMOTE_BY_ID`, not on the wheel). Procedural sounds (crunch, gulp, burp, hic, pop, clink) via `mods.soundGens`. Fizzy drinks burp.
* **Social**: CHEERS! = 2+ drinkers within 4 m / 3 s (host detects) gives Liquid Courage for 60 s. Party Cake gives everyone within 8 m Cake Day (60 s + 30 s per extra guest). **H** holds food out, a crewmate presses E, the host moves the item. Ship mess **table + stools** (first free of `TABLE_SPOTS`): two players eating there within 30 s (or a solo player) get **Well Fed** (240 s) at the next landing. Vending machines + fridges (0-2 per facility, seeded) dispense 3 / 2 items via the host.
* Net (all `fd*`): `fd` request (use / offer / take / vend / pass), `fdfx` host to all (HOST_ONLY), `fds` peer state (relayed). The host removes the item and announces `ate`; effects apply on the eater's client.
* Not done / risks: never run in a browser (arc poses, blur overlay, table position, machine rotation are unverified visually); booze courage only refunds STATIC (no other fear system exists); chat bubbles do not exist yet, only the chat line is slurred.

**UPDATE (wave 4, survival):** packaged snacks are now weak (Pizza Slice 12 HP, Pizza Box 24, Party Cake 15, Instant Noodles 0.5 HP/s, Deluxe Ramen 0.8 HP/s); real healing comes from cooked meals (docs/wave4/survival.md). `applyEaten` emits `tfg:ate` so snacks feed the hunger meter a little.
