It contains no image, external texture, light, skeleton or animation. The actor shares the rounded coverall/CRT style of native avatar2, with a recognisable service pose rather than three cubes. All original cube-clerk meshes and duplicate desk facing were removed; the desk's existing native collision/interaction remains. Two explicit native cast-jamb colliders and one overhead lintel collider match the new facade instead of using its whole-model bounding box, so the centre opening remains traversable.
