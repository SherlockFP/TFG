# Shot fixes from hud6_torch.jpg (wave 8)

1. **Tofu at the end of the Algorithm line** ("...TUTORIAL SKIP at ░▯"): not a key placeholder. It is the intercom typewriter's scramble tail (`algorithm.js` `GLYPHS`, two random glyphs after the revealed text) drawing block glyphs (`▯ ░ ▒ ▓ ▮`) the HUD font lacks. GLYPHS is now printable ASCII only. No `[KEY]` token was involved (key names are substituted by i18n `tf`; checked `guide_data.js`).
2. **Waypoint clutter** (`tasks.js updateMarks`, Among-Us style crew tasks): the named world label now floats only for the NEAREST open task and only while tasks own the ONE goal (`objectives.goalSrc`, new one-liner in `objectives.js update()`). Every other open task is icon + distance on the screen edge only (hidden while on screen: the station has its own marker); clamp margin 90 px for named labels / 34 px for icons, so "Fix Wiring" is never cut off. The hold-Tab card still lists all tasks.
3. **Floating magenta cube** = the algo2 FREEZE glitch exploit (`algo2_view.js`: a spinning octahedron with the flicker shader in pink). Restyled: a dead CRT monitor on a crate sitting on the floor, screen full of phosphor static, no spin. All three glitch kinds (wall / dup / freeze) use CRT phosphor colours (green / amber / grey) and the pink tear tint is neutral. Gameplay (positions, use radius, ids) unchanged.
