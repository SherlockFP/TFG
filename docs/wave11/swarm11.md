# Wave 11 - SWARM11 (module `swarm11`, src/game/swarm11*.js, src/models/swarm11_models.js)

Creature ecology: creatures that interact with loot, light and each other. Each has ONE rule, a silhouette + emissive tell, a sound, a telegraph >= 0.8 s and counterplay. Host-authoritative; one net message (`swfx`, host -> all, HOST_ONLY). Everything else rides the generic creature channels (`cev sp/snd/hp/die`, `cs` rows where `extra` carries nest fill / ring health / flag meter), so late joiners get creature state for free; the blood stains are re-sent on `playerJoin`.

Files: `swarm11.js` (installer, seed, blood wraps, debug), `swarm11_core.js` (TUNE + pure rules, node-tested), `swarm11_ai.js` (DEFS, host AI, host tick, colony spawn, registration), `swarm11_fx.js` (blood decals, AutoMod aim beam, speech tags, toasts), `swarm11_sfx.js` (15 procedural sounds), `swarm11_text.js` (TR + RU), `models/swarm11_models.js`. Test: `node tools/harness/swarm11.test.mjs` (14 checks).

## Extends, does not duplicate
The game already had the wave-1 **Collector** (single skittish thief, tiny pile, `hoardnest` prop) and **Janitor Bot** (bins tools, mops blood trails, closes doors). Scrapers reuse the Collector's carry protocol (`held` `c:<id>` / `drop` item messages, `dropAll()` exported from `creatures_wave1.js`) and its loot rules, but are a colony with a smashable, glowing nest and a wake-up rule. The AutoMod is the dangerous cousin of the Janitor Bot (it only cares about what the CREW left; the Janitor keeps its tool bin). Chalk is removed through the horror module's own store (`game.horror.store.remove` + the `hrch` message). "Blood" = new pooled decals recorded where a crewmate was hurt (there was no persistent player blood); the facility's set-piece blood trails stay the Janitor Bot's job. The outdoor `giant` is already displayed as "Influencer", so ours is **The Streamer**; the shotgun `moderator` is "The Moderator", so ours is **AutoMod**.

Dropped loot is a timing decision. |

## Integration
- `registerCreature` for all four; `sw_streamer` / `sw_automod` are in `EXTRA_SPAWNS` (`TUNE.spawn`, tier 1 = 0) behind a `noSpawn` getter (quota index >= 1) like creatures10; scrapers + nest are `noSpawn: true` and spawned by the module on `moonPopulated` (seeded `RNG(hash(run.seed, moon, day, quota))`, chance 35 % + 50 % when the pool lists them + 2 %/quota; quota 0 = 5 bots). Nest room: the smaller 60 % of rooms (not entrance / vault / generator), >= 16 m from the main door, on the nav grid.
- Threat pool: three rows in `threatpool.js` HEADLINE (`sw_scraper`, `sw_streamer` minQ 1, `sw_automod` minQ 1). crdirector: the states of the Streamer / AutoMod that are not in its CALM set count as threat (the Streamer has dmg 0 so it is never budgeted, by design).
- IDENT / FIELD_NOTES / STATE_SOUNDS / LOOPS / CREATURE_FLAVOUR / NO_TELL rows, death texts, `addTranslations` TR + RU (`swarm11_text.js`, one [EN, TR, RU] table).
- Host cost: one 0.25 s tick (one pass over the item map + chalk + blood, bounded lists), scrapers <= 8 with `goToLazy` for static goals, streamer pulses every 1.5 s with an A* budget of 6, AutoMod scans every 1 s. No per-frame allocations in the AI (scratch object for the item rules).
- Blood: `hostHurtPlayer` and `hostOnPlayerDied` are wrapped from the module (restored on dispose): a hit >= 5 leaves a stain, a death a big one; stains within 1.4 m merge; 28 max; one 32-quad InstancedMesh.

## How to see it (host, in a facility)
`kefal.game.swarm11.debug.colony()` (nest + 6 bots 10 m ahead), `.dropScrap()` (loose scrap for the bots AND a dropped item for the AutoMod), `.smashNest()`, `.streamer()` then `.goLive()`, `.automod()`, `.body()` (stand next to it to get flagged), `.blood()`, `.state()`.

## Not verified (no browser run)
- Nothing has been seen in the game: the four models (proportions, ring / beam glow, the pull rings on a real floor, the aim beam), the item on the bot's tray (`parts.carry` anchor), sound levels, the nest room choice on real layouts, and how the calm creatures of the real roster respond to `goTo` + `walk` (some behaviours own their own idle loop; the noise pulse helps those that listen).
- Host migration rebuilds creatures without `data`: scrapers re-adopt the nearest nest and the nest re-adopts nearby scrap; the AutoMod / Streamer restart their timers.
- The chalk removal path needs the horror module active (`game.horror.store`); without it chalk is simply not a target.
