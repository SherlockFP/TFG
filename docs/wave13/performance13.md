# Wave 13 performance audit

Evidence and changes:

- `gpusweep.js` previously traversed the entire landed scene every five seconds. Its prior source records a roughly 90 ms landed-map traversal. The periodic scan now visits at most 128 nodes or spends 1.5 ms per update, with a resumable child cursor so even a scene with thousands of direct children cannot push all children in one update. Draw-time resource tracking still catches short-lived objects. Final orbit cleanup remains synchronous over the much smaller surviving scene.
- Reused materials were permanently marked as already inspected even after a sweep cleared known textures. The draw hook now records sweep epochs, so the same material contributes textures again on later maps. The existing cleanup harness adds wide-scene bounded-progress and repeated-material-epoch regressions.
- Cargo driving previously created roughly 19 vectors per update for movement and collision probes. Ten installer-local scratch vectors now serve these synchronous paths. Every collision probe and floor check remains present. Cargo objects are reparented only when their parent changes. A trolley collider now changes its Rapier pose only when position/yaw/collider identity changes, avoiding idle broadphase dirtiness. Physics and rendering detail are preserved.
- The perf fixture returned empty objects for `addStaticBox`, unlike real Rapier colliders. Cargo's valid `setTranslation`/`setRotation` calls generated repeated stub exceptions. The fixture now models those two methods. That correction prevents logging overhead from being mistaken for gameplay CPU cost.

Measurements (Node, this execution environment, not browser FPS): a synthetic 16,001-node wide scene has a full traversal median of 4.24 ms; the incremental scanner's maximum update is 0.332 ms across 126 updates (scanner portion max 0.314 ms). Total cleanup work is distributed, not removed. The broad perf5 simulation now passes with sum of handler medians 0.557 ms/tick over 130 handlers; cargo median 0.0032 ms, max 0.040 ms. The old cargo 0.159 ms failure includes invalid fixture collider errors, so it is not a valid live before/after speedup comparison.

Validation: gpusweep cycle harness passes 20 checks; eight repeated maps return resident geometry to baseline (89 during / 48 before sweep / 1 after); SFX harness passes 6,879 checks after registering real threat definitions in its creature fixture. The existing perf harness passes. Browser GPU/frame-time evidence is reserved for shared QA and may differ significantly from Node. No render resolution, geometry detail, audio feature or gameplay system was disabled.

WebGL feedback warning investigation: engine scene renders into its offscreen target, then explicitly sets target=null before sampling that target in its postprocess quad. Camera photography renders into a separate target and restores the previous target in finally. No observed source-level feedback violation was found; therefore those paths were not altered speculatively. QA should retain the warning as unresolved until its producing draw/material is identified.
