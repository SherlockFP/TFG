# Wave 8 i18n8: a Turkish (and Russian) player sees no English in normal play

Goal: close the "about 370 keys per language" tail from `docs/wave8/studio.md`, plus what the static audit could not see.

## What the numbers meant

`tools/i18n_audit.mjs` is a static (AST) scan. It reported MISSING TR 501 / RU 498 (baseline in the style guide said 373 / 370).
Nearly all of those were false positives: modules such as survival, resto, zones, story, cycle3, feedcams, facjobs, hub, mining, harvest and dance
build their dictionaries at import or install time (ROWS tables, `buildDictionaries()`, `fresh(TR, 'tr')`), which a static scan cannot follow.
The real holes were elsewhere: **data tables and literals that never reach a dictionary** (passive tree, pets, item tips, cosmetics, creature
lore, minigames, XP feed reasons, terminal replies, ship monitors) and **keys that only had a Turkish twin** (no Russian).

## Tools (both read-only reports, exit code 0)

- `node tools/i18n_audit.mjs` (upgraded): now imports every pure `*_i18n / *_text / *_data / ru_gap8_*` file in node so the live dictionaries are
  counted, recognises `{ 'English': ['tr', 'ru'] }` install-time tables, knows the new wrappers (`_t`, `_tf`, `tt`, `tNum`, `tmg`), and marks unwrapped
  findings that a dictionary already covers. New flag `--gaps` prints the TR-only / RU-only keys with their source.
- `node tools/i18n_runtime_audit.mjs [--list tr|ru] [--file <substr>] [--json out.json]` (new): imports every module under `src/` with css / assets
  stubbed, runs every exported `install*()` against a permissive proxy `game` (so `addTranslations` / `registerItem` / `registerCreature` really run),
  then walks every exported data table and lists display strings (`name desc tip lore short label title blurb hint text tag ...`, including string
  arrays) that have no TR / no RU entry. Blind spots: arrays of length 2 or 3 are treated as bilingual `[en, tr, ru]` pairs and skipped; strings that
  the game builds by concatenation are only checked as whole values.

Voice follows `docs/wave8/studio_style.md`: no em dashes, no decorative "!" (kept only where the English is an alarm), credits `▮`, Clout `◈`, key hints in `[E]`
form, TR `%15` order, "kovuldun" / "забанен" for deplatformed. Placeholders (`{n}`, `{@name}`, `{code}`, `▮`, `[E]`) are identical in every language; a parity
check over all 1,550 new rows found 0 mismatches (`globalThis.__fillLog` in `fill.js` exists for that check).

## Code changes (small, each with the reason)

- `display.js`: `localizeDeep` for the passive tree (`KEYS`, `ROLES`, `KEYSTONES`, `NODES`) and `LORE_LOGS` titles, so every existing read site shows the language.
- `passivetree.js`: `formatBonus` writes `+%3` for Turkish (percent first); imports `getLang` only. Panel: keystone / node `text` lines, "INFO", node counters go through `t` / `tf`.
- `hud.js` (safety nets): XP-feed reasons (`xpReason`: exact key or `<Crafted|Dismantled|Analysis:|Contract:|Task:|Ship fault:> <name>`), `bigText`, `showToast`, `setPrompt`
  (interaction prompts), scan labels, compass marks, `floatText` (number-aware). `actions.js`: carry / grab prompts use `tf`.
- `terminal.js`: `print()` runs each line through `tNum` (exact key, then numbers as `{}`); `modapi.js`: HELP lists `t(help)`.
- `src/i18n/tnum.js` (new): the number-aware translator shared by terminal, HUD floats and minigames.
- `minigames/common.js`: every drawn / status / help / title string goes through `tmg` (= `tNum`); the 3x5 pixel font gained Cyrillic (it stripped Turkish diacritics
  already), so Russian minigame text no longer renders as `?`.
- `screens.js` (ship monitors), `shipyard.js` (ship canvases), `record.js` (service record), `crafting` / `pets` / `inventory_panel`, `models/anomaly|board|shipyard`,
  `durability.js`: literals wrapped in `t` / `tf`. `trade.js`: "{n} item(s)" became "Items: {n}" (no "(s)" plurals).
- `tools/i18n_audit.mjs`, `tools/i18n_runtime_audit.mjs`: see Tools. `docs/wave8/studio_style.md` checklist points at both.

## How to test

- `npm run build`; `node tools/i18n_audit.mjs` and `node tools/i18n_runtime_audit.mjs` (numbers above).
- Node tests of touched modules, all green: arcade2 (23), guide (2179), hud6, hudcalm (17), shipyard (20), shipyard_models (118), shipyard_install (28), polish4 (16),
  threatmerge (32), wave1_tree (1913), ship2_install (21), br_i18n, cycle2_i18n.
- Spot check: `setLang('tr')`, `formatBonus('moveSpeed', 0.03).text` is `+%3 Hareket Hızı`; `tmg('SEAL 50%   12s')` is `MUHUR %50   12sn`.

## Left (honest list)

- Template-literal messages that interpolate names / numbers without `tf` (echo "{} is recharging", factions tribute lines, rpgctl refund costs, football goal toast, creature-tier
  spawn announcements): the key with `{}` cannot match at runtime. Each needs its call site turned into `tf('... {name} ...', {...})`.
- In-world canvas textures written once at build (menu room monitors, backrooms level signs, mapart posters, `PLOT [E]`, `LULLABY`, `SECTOR 1`): English, not wrapped.
- 1071 static "unwrapped" findings remain in the audit: mostly bilingual `[en, tr]` data (menuterminal, guide, loredata), string fragments of longer sentences,
  shader / CSS / font strings and dev-only text. The real gaps in that list are the two bullets above.
- Not verified in a browser (no browser run was allowed): pixel widths of the longer TR / RU minigame lines in the 160 to 200 px canvases, how the new Cyrillic 3x5
  glyphs look, and the ship monitor line lengths in RU.
- Panel-local TR tables (achievements, passive tree panel, service record, daily events) still serve Turkish; Russian reaches them through the global dictionary.
